LXGW WenKai (霞鹜文楷), regular weight, Simplified Chinese cut.

Font: https://github.com/lxgw/LxgwWenKai, SIL Open Font License 1.1.
Web subsets: npm package lxgw-wenkai-webfont 1.7.0 (MIT), files copied unchanged:
lxgwwenkai-regular.css and files/lxgwwenkai-regular-subset-*.woff2 (97 slices, 4.6 MB;
a browser downloads only the slices whose characters appear on the page).

Self-hosted because the cut on Google Fonts is the Traditional one, which centres ，。 in the line.
